# StreamPro - Plataforma Mayorista y Distribución de Streaming

Plataforma inteligente para la gestión, venta y distribución de cuentas de streaming y catálogo físico.

## 🚀 Características
- **Tienda Oficial**: Suscripciones digitales, combos con ofertas automáticas y catálogo de productos físicos.
- **Panel de Distribuidor (CRM)**: Gestión de clientes, billetera virtual de saldo a favor, cálculo de comisiones (1% tienda, 3% link compartido) y generador de flyers publicitarios en HD.
- **Centro Mayorista Proveedor**: Control de inventario multi-perfil, auditoría de revendedores y liquidación de pedidos.
- **Bóveda del Cliente**: Consulta segura de accesos, PINs y seguimiento de compras en 3 pasos simples.

## 🛠️ Tecnologías
- Vue 3 (Composition API / `<script setup>`)
- Vite 8
- Pinia Store
- Tailwind CSS
- PWA (Progressive Web App)

## 📦 Instalación y Desarrollo
```bash
npm install
npm run dev
```

## 🏗️ Compilación de Producción
```bash
npm run build
```
